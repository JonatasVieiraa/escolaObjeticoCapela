# Colégio Objetivo Capela do Alto - Landing Page

📋 **Sobre o Projeto**  
Este projeto consiste em uma landing page moderna e responsiva desenvolvida para o Colégio Objetivo de Capela do Alto. O site foi criado com o objetivo de proporcionar uma experiência digital intuitiva e agradável para pais e alunos, facilitando o acesso às informações da instituição.

🚀 **Tecnologias Utilizadas**
- HTML5
- CSS3
- JavaScript

✨ **Características**
- Design moderno e atraente
- Layout totalmente responsivo
- Interface intuitiva e de fácil navegação
- Otimizado para diversos dispositivos e navegadores
- Performance e carregamento rápido

🖥️ **Demonstração**  
Para visualizar o projeto em funcionamento, acesse: [Colégio Objetivo Capela do Alto](https://colegioobjetivocapela.com.br/)

🎯 **Funcionalidades**
- Apresentação das informações institucionais
- Seção de cursos e programas educacionais
- Galeria de fotos e eventos
- Formulário de contato
- Informações sobre processo de matrícula
